PHASE 1: DATA PREPARATION
┌─────────────────────────────────────────────────────────────────────────────┐
│ Raw CSV: 1M+ rows                                                           │
│ ├─ WO No. (Work Order ID)                                                  │
│ ├─ Description (Problem summary)                                            │
│ └─ Text (Technician notes)                                                 │
│                                                                              │
│ Data Quality Issues:                                                        │
│ ✗ Many #N/A values                                                         │
│ ✗ Invalid WO numbers                                                       │
│ ✗ Empty descriptions/notes                                                 │
│ ✗ Technician names (BRAD, CHAD, FOX)                                       │
│ ✗ Inconsistent formatting                                                  │
│                                                                              │
│ Cleaning Pipeline:                                                          │
│ 1. Drop all-empty rows                                                      │
│ 2. Filter valid WO numbers (numeric only)                                   │
│ 3. Remove empty Description or Text                                         │
│ 4. Strip whitespace                                                         │
│ 5. Create cleaned columns (lowercase, remove punctuation)                   │
│                                                                              │
│ Result: ~40K valid records (from 93K with content, from 1M raw)            │
└─────────────────────────────────────────────────────────────────────────────┘

PHASE 2: UNSUPERVISED CLUSTERING (Generate Labels)
┌─────────────────────────────────────────────────────────────────────────────┐
│ Input: Text_cleaned (technician notes from 40K records)                    │
│                                                                              │
│ ┌─────────────────────────────────────────────────────────────┐            │
│ │ TfidfVectorizer(stop_words='english', max_features=5000)    │            │
│ │ → Converts text to weighted word vectors                    │            │
│ │ → Learns importance of each word                            │            │
│ └─────────────────────────────────────────────────────────────┘            │
│                         ↓                                                    │
│ ┌─────────────────────────────────────────────────────────────┐            │
│ │ KMeans(n_clusters=5, random_state=42)                       │            │
│ │ → Groups similar notes into 5 behavior clusters             │            │
│ │ → Selected k=5 based on silhouette score (k=2 to 9)        │            │
│ └─────────────────────────────────────────────────────────────┘            │
│                         ↓                                                    │
│ Output: Note_Cluster (0-4) for each record                                  │
│                                                                              │
│ Cluster Characteristics:                                                    │
│ ┌────┬──────────────────┬──────────────────────────┬──────────────┐       │
│ │ ID │ Name             │ Top Words                │ Size (%)     │       │
│ ├────┼──────────────────┼──────────────────────────┼──────────────┤       │
│ │ 0  │ Adjust/Clean     │ reset, adjusted, cleaned │ 73% (8250)   │       │
│ │ 1  │ Replace Parts    │ replaced, fuse, belt     │ 19% (2096)   │       │
│ │ 2  │ Simple Complete  │ complete, [names]        │ 2.5% (282)   │       │
│ │ 3  │ Repair Broken    │ broken, repaired, wire   │ 2.5% (287)   │       │
│ │ 4  │ Electrical/Wire  │ repaired, wiring, leak   │ 3.4% (388)   │       │
│ └────┴──────────────────┴──────────────────────────┴──────────────┘       │
│                                                                              │
│ Problem: SEVERE CLASS IMBALANCE                                             │
│ ⚠ Cluster 0 dominates (73%), others are minority                          │
└─────────────────────────────────────────────────────────────────────────────┘

================================================================================
                            SUMMARY OF ISSUES
================================================================================

HIGH SEVERITY:
[1] Class Imbalance
    - Cluster 0: 73% of data
    - Model defaults to predicting Cluster 0
    - Minority classes (2-4) have <10% recall

[2] Data Quality
    - Technician names contaminate text features
    - Filler words ("completed", "done") should be removed
    - README notes this issue but it's not fixed in code

MEDIUM SEVERITY:
[3] Model Performance
    - Overall accuracy 74% (moderate)
    - Precision for minority classes < 0.5
    - Cannot reliably predict Clusters 2-4

[4] Feature Engineering
    - TF-IDF may miss semantic relationships
    - No contextual embeddings (BERT, etc.)
    - Stop words may remove domain-specific terms

LOW SEVERITY:
[5] Code Organization
    - Single notebook file (hard to maintain/deploy)
    - No modular structure
    - No configuration management
